# Aaditri Mishra — Personal Portfolio & Journal

A modern, responsive, and interactive personal portfolio landing page with an integrated Markdown-based blog. Built using clean HTML5, CSS3, modern JavaScript, and Marked.js.

## ✨ Key Features

- **Dark Obsidian Aesthetics:** Styled with neon violet and cyan ambient blur gradients.
- **Dynamic 3D Tilt Cards:** Interactive cursor-tracking 3D tilt effects on skills, projects, and blog cards.
- **Interactive Particle Background:** HTML5 Canvas particle system reacting in real time to mouse interaction.
- **Dynamic Markdown Blog Reader:** Fetches local `.md` articles and parses them smoothly into clean HTML without page reloads.
- **Scroll Reveal Animations:** Smooth scroll-triggered entry transitions.
- **Fully Responsive:** Styled for mobile, tablet, and desktop screens.
